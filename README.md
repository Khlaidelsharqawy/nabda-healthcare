# Nabda Healthcare Platform (منصة نبضة للرعاية الصحية)

منصة رعاية صحية متعددة المستأجرين مدعومة بالذكاء الاصطناعي (Multi-Tenant AI Healthcare Platform).

## 📁 هيكل المشروع (Project Structure)

```
nabda-healthcare/
├── frontend/               # الواجهة الأمامية (React + TypeScript + Vite)
│   ├── src/                # الكود المصدري للواجهة والمكونات
│   ├── docs/               # وثائق التصميم والمعمارية
│   ├── frontend/           # النماذج الأولية والشاشات (Screens & Prototypes)
│   ├── package.json
│   └── vite.config.ts
├── .gitignore
└── README.md
```

## 🚀 تشغيل الفرونت إند محلياً (Getting Started)

```bash
cd frontend
npm install
npm run dev
```
